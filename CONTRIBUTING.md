# Contributing

## Branch naming

```
<commit_type>/<description>
```

- `commit_type`: one of `feat`, `fix`, `doc`, `chore`
- `description`: kebab-case, 45 characters or fewer, a concise summary of the work

Examples: `feat/add-reset-button`, `fix/counter-negative-values`, `doc/update-readme`, `chore/bump-vite`.

## Pull requests

`main` requires a pull request and six passing checks (see `CLAUDE.md`). Fill in the PR template.
